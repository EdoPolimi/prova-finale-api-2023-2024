# Prova Finale Algoritmi e Principi dell'Informatica 2023-2024

## Description
An event-driven simulation system developed in standard C to optimize warehouse inventory and dynamic order scheduling for an industrial bakery. 
The system efficiently processes incoming commands, manages expiring ingredient batches, and orchestrates order fulfillment based on chronological priority and weight limits. 

## Technical Details & Constraints
* **Language:** C
* **Data Structures:** Custom implementation of efficient data structures to handle time-discrete events.
* **Performance Constraints:** The system was engineered to strictly operate under a 25 MiB memory limit and a 9-second CPU execution time.
